# 使用请求示例

可以把本组件 Skill 交给 AI，并提出下面这样的任务。

> 给这篇公众号的文末加入一个 72px 的头像跳转组件，下面写“点击头像，认识一下”。这是我的公众号名称或一篇已发表文章的链接，头像可以沿用账号当前头像。我已经在浏览器登录了后台，请先帮我取得这个账号的原生名片，生成后插入本篇草稿，保存重开并检查，最后给我手机预览。需要我补充什么，一次告诉我。

AI 应先根据账号线索和已有登录定位目标公众号。用户已经给了原生名片时直接提取。尚未取得名片时，AI 查看当前 snapshot，找到原生名片插入入口，搜索并核对账号，再读取插入后的组件，保存到本次工作目录。

需要用户接手登录或当前工具无法读取时，说明实际缺项，并引导完成相应操作，再继续运行。官方获取步骤可用于定位操作方向。[获取公众号卡片代码](https://www.135editor.com/books/chapter/1/489)

取得真实名片后，使用本次实际文件运行。

```text
python scripts/render_avatar.py --card-html account-card.html --out avatar-component.html --size 72 --caption "点击头像，认识一下"
```

渲染脚本发现名片缺少名称和头像时，返回结果包含对应字段。AI 应优先回到当前编辑器核对和重新取得完整名片，确需用户补充时再集中提示。

```json
{
  "status": "needs_input",
  "missing": ["公众号名称 data-nickname", "头像地址 data-headimg"],
  "issues": []
}
```

用于测试脚本的合成名片只能证明处理逻辑。实际文章使用目标公众号在编辑器中提供的原生名片。
