# 正文排版组件

根据内容关系选择组件。章节用标题，操作顺序用步骤，有限维度比较用表格，必要图片带图注。一般叙述保持普通段落。

## 材料与缺项

读取用户正文、组件放置位置和现有主题。仅排版时保留原文。图片需要真实文件或可访问的托管地址。表格需要完整表头和各行数据。缺失材料集中列出，并说明补充格式。

`examples/blocks.json` 展示输入结构。`blocks` 是按顺序排列的组件，各项用 `type` 指定种类。主题可传 `accent`、`text`、`muted`、`surface`、`border` 五个 HEX 色值，缺省采用示例中的中性色。

## 生成

```text
python scripts/render.py --spec examples/blocks.json --out /本次输出目录/blocks.html --preview /本次输出目录/preview.html
```

路径按当前环境替换。`--out` 生成可插入的 HTML 片段，`--preview` 可选，生成可直接打开的浏览器预览。输出文件已经存在时需要显式提供 `--overwrite`。

脚本会集中返回缺项或输入错误。把清单转成用户能回答的问题，补齐后继续。

## 插入与检查

需要编辑秀米时，先读取当前浏览器工具说明。使用富文本粘贴入口先试一小段，观察文字、颜色和结构是否保留，再继续整篇。

检查标题换行、步骤顺序、表格列数、图像比例和正文是否完整。用320px及375px宽度检查横向溢出和文字可读性。保存后重开实际草稿，再核对这些内容。

深色模式按本次主题实际检查。生成片段对颜色节点设置 `data-no-dark`，编辑器和手机保留效果以本篇实测为准。

## 当前验证范围

生成脚本和本地窄屏预览按本包验证记录填写。新的公众号草稿仍需检查保存、手机浅深模式及素材加载。
