# 杂志跨栏图文

用于小鱼 Fred 的公众号排版外挂组件库。默认视觉沿用暖橙、奶油纸色与橙帽头像。替换为用户资料时保留内容真实性。

## 先收齐输入

主图、图注、2至4组短标题与正文、一句收束文字。

可直接复制 [示例配置](examples/config.json)。缺资料时列出具体缺项，收齐后生成。

## 本地生成与预览

在本Skill解压目录运行。

```text
python scripts/render.py --config examples/config.json --out examples/component.html --preview-out examples/preview.html --overwrite
```

用浏览器打开 [交互预览](examples/preview.html)。[HTML片段](examples/component.html)保留文字和布局结构，可由AI按个人风格调整。[生成器](scripts/render.py)使用Python标准库，素材随包携带。普通图片嵌入输出，视频保留本包相对引用，请一起移动整个目录。

生成前先检查输出路径并独占输出锁，片段与预览全部暂存后再提交。覆盖失败会恢复旧文件，恢复或清理遇到问题时会返回保留备份及中间输出的位置。

## 秀米与公众号操作

在秀米用多列布局放置图文，手机宽度以阅读顺序为准。必要时把两栏转为上下排列，保持正文为可编辑文字。逐项核对导入前后的字号、边距和图片比例。

## 检查再交付

- 在320px和375px宽度检查换行、溢出和文字可读性。
- 逐项操作预览，核对内容、媒体和阅读顺序。
- 保存并重开目标图文，确认组件仍在，再同步公众号检查手机效果。
- 本轮本地浏览器验证与秀米菜单调研分别记录，目标账号保存、同步和手机结果以实际操作为准。

## 使用边界

本地HTML片段用于设计、预览和AI理解。公众号会处理导入代码，交互效果请按以上原生操作完成。缺少登录态、账号权限或有效素材时，明确列出待补项目。所有问答、访谈和表格内容在发布前交作者复核。

## 调研依据

2026-11-16通过Ego lite实际查看秀米图文编辑器的布局、SVG与组件分类。原生菜单与模板提示来自 [秀米](https://xiumi.us/)。新视觉使用Fred已有自有素材。

## 品牌演示与GIF

[查看原生排版示例](examples/brand-preview.html) · [查看GIF](examples/demo.gif) · [读取品牌样式与素材](examples/brand-style.json)

1. 先看GIF选择效果，再读取 `examples/brand-style.json` 和 `examples/brand-component.html`，确认本组件的画布、配色及素材。
2. 按本次任务采用使用者自己的头像、账号资料、正文与配图。直接修改本地品牌HTML模板和相邻素材即可复用单项包。原有生成器的参数能力以本Skill正文为准。
3. 文字与图注保留原生HTML。沿用横滑、展开或视频控件；涉及秀米和公众号的部分按本Skill原生入口制作，再核对保存、同步和手机表现。
4. 修改后检查完整动作与返回，核对文字、图片和按钮边界，再检查目标编辑器中的保存结果。

本版已有600px浏览器操作／播放采集、320／375px布局检查，GIF记录与实际文件校验一致。

品牌输出的秀米保存重开、公众号同步与真实手机微信效果待按目标环境核对。
