# 百叶窗分条展开

六条水平窗叶错峰收起，露出同一张内容卡。点击反方向按钮，窗叶依次恢复。可用于章节开场、短寄语或结论揭晓。

## 材料与生成

提供组件标题 `title`、卡片标题 `content_title` 和正文 `body`。卡片标题最多一行约13个全角字，正文最多四行。需要一整篇长内容时，将详细文字放在组件之后。

调整[配置示例](examples/config.json)。`accent`、`background` 为六位HEX颜色，`duration` 为所有窗叶完成动作的合计时长，支持0.4～3秒。

```text
python <本Skill目录>/scripts/render.py --config <本次目录>/config.json --out <本次目录>/component.html --preview-out <本次目录>/preview.html
```

已有输出需要替换时加 `--overwrite`。片段和预览使用 `.html` 或 `.htm`，输入配置、Skill说明和生成器受保护。脚本保留输入文字并做XML转义，缺项、超长或非法数值会报告字段。

打开[交互预览](examples/preview.html)，点击亮起的按钮。动画结束后再切回，灰色按钮暂不响应。

## 接入与检查

- 检查窗叶按顺序错峰收起，全部打开后卡片内容完整。
- 合上再打开，连续两轮核对窗叶归位。
- 初始反向、快速连点和重复同向点击应保持合理状态。
- 在320、375px检查标题、正文、按钮及窗叶边界，同篇双实例分别操作。
- 秀米保存重开后从阅读页打开和合上，再核对公众号同步与手机微信。

片段采用SVG与SMIL。事件ID每次独立生成，点击锚点位于 `g` 节点。秀米清理数据属性后，可用 `g[id^="blinds_"][id$="_forward"]` 和 `_reverse` 定位。六个 `_slat_0` 到 `_slat_5` 组的纵向缩放在1与0之间变化。


参考笔记的标题与正文介绍百叶窗展开显示图片，本包将分条展开改为读者点击控制，使用原创矢量窗叶和文字卡片。视频内容尚未纳入本轮阅读范围。[小红书参考案例](https://www.xiaohongshu.com/explore/60e7c169000000000100781e)

## 品牌演示与GIF

[查看可操作演示](examples/brand-preview.html) · [查看GIF](examples/demo.gif) · [读取品牌样式与素材](examples/brand-style.json)

1. 先看GIF选择效果，再读取 `examples/brand-style.json` 和 `examples/brand-component.html`，确认本组件的画布、配色及素材。
2. 按本次任务采用使用者自己的头像、账号资料、正文与配图。直接修改本地品牌HTML模板和相邻素材即可复用单项包。原有生成器的参数能力以本Skill正文为准。
3. 文字保留原生编辑。图片放在对应动画组或状态组里，保留事件ID、SMIL时序与透明点击区。同篇放多个实例时，分别生成独立ID并同步事件引用。
4. 修改后检查完整动作与返回，核对文字、图片和按钮边界，再检查目标编辑器中的保存结果。

本版已有600px浏览器操作／播放采集、320／375px布局检查，GIF记录与实际文件校验一致。

品牌输出的秀米保存重开、公众号同步与真实手机微信效果待按目标环境核对。
