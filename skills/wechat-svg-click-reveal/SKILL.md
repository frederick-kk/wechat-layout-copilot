# 固定画面点击揭秘

在600×360的固定画面中，读者先看到提示，点击后渐显答案。适合一条短知识、一个问题或一个小彩蛋。画面高度始终固定，段落的排版高度也保持固定。

## 收集输入

- 必需材料是点击后要显示的文字，或用户确认过的图形内容。当前脚本直接生成文字版本。
- 提示语、强调色、底色可选。默认提示语为“点一下，查看答案”，默认强调色为 `#D97706`，默认底色为 `#FFF8EE`。采用默认值时告知使用者。
- 确认放入的文章和位置。进入编辑器时再确认工具、登录状态和目标草稿。
- 信息缺失时集中提示，例如“请补充点击后显示的文字，以及本次要放入的文章位置”。重要解释仍放在可直接阅读的正文中。

## 生成与微调

```text
python <本Skill目录>/scripts/render.py --answer "先准备正文、参考文章和图片，再让AI检查缺项。" --out <本次目录>/reveal.html --preview-out <本次目录>/reveal-preview.html
```

`--prompt` 可更换点击前提示，`--color` 可换强调色，`--background` 可换底色。已有输出须在本次允许替换后加 `--overwrite`。

画面文字为36单位，行距44单位，每行约14个全角字。提示最多三行，答案最多五行。脚本按中英文字符的估算宽度换行并保留原文。超过容量时，脚本会报告本次实际行数，提示补充用户确认过的精简版本，或确认拆成多个组件。

需要图形版时，读取 [references/implementation.md](references/implementation.md)，在同一个答案层中用本地SVG形状绘制，继续保留透明热区和一次点击的时序。

## 检查与编辑器使用

1. 打开独立预览，确认初始只显示提示，答案层透明。
2. 点击画面，答案应在约0.28秒内显示。等待后答案持续可见，再次点击仍保持该答案。
3. 核对点击前后组件高度一致，并在320px、375px视口检查文字。预览留边后最窄SVG宽272px，36单位文字实际约16.32px。检查各行边界完整，刷新页面可重新开始。
4. 插入本次编辑器、保存并重新打开，检查SVG、动画标签和属性是否保留。
5. 在公众号草稿的手机预览中核对触发、完整内容与颜色。实际编辑和同步遵循用户本次授权。

2026-11-11本版已完成生成、结构自检、Ego lite真实鼠标点击和320px、375px窄屏验证。两种视口点击后答案层opacity均从0变为1，组件高度保持一致。320px视口中的实际文字约16.32px，375px视口约19.64px，示例文字边界完整。秀米及微信保存重开、手机触发继续待实测。当前组件的内容显示发生在固定画面内，教程应使用“点击揭秘”或“固定画面显示答案”描述。

示例见 [examples/preview.html](examples/preview.html)。实现与技术依据见 [references/implementation.md](references/implementation.md)。

## 品牌演示与GIF

[查看可操作演示](examples/brand-preview.html) · [查看GIF](examples/demo.gif) · [读取品牌样式与素材](examples/brand-style.json)

1. 先看GIF选择效果，再读取 `examples/brand-style.json` 和 `examples/brand-component.html`，确认本组件的画布、配色及素材。
2. 按本次任务采用使用者自己的头像、账号资料、正文与配图。直接修改本地品牌HTML模板和相邻素材即可复用单项包。原有生成器的参数能力以本Skill正文为准。
3. 文字保留原生编辑。图片放在对应动画组或状态组里，保留事件ID、SMIL时序与透明点击区。同篇放多个实例时，分别生成独立ID并同步事件引用。
4. 修改后检查完整动作与返回，核对文字、图片和按钮边界，再检查目标编辑器中的保存结果。

本版已有600px浏览器操作／播放采集、320／375px布局检查，GIF记录与实际文件校验一致。

品牌输出的秀米保存重开、公众号同步与真实手机微信效果待按目标环境核对。
