# 点按礼花

阅读点燃烟花、向上展开与出现祝福的正文，本包采用固定粒子绽放和自定义文字。[小红书参考案例](https://www.xiaohongshu.com/explore/67580321000000000700ae90)

## 材料与行为

需要 `title` 与 `message`，祝福最多两行、每行约14个全角字。`duration` 为礼花完整时长，范围0.6～4秒。`particles` 可选8～24，默认16。强调色和底色采用六位HEX。

点按后小彩纸向不同方向散开并淡出，祝福随后保留，完成后可以重播。需要抽签或有奖活动时，先另外明确其逻辑和规则。

检查末帧全部粒子透明度为0、祝福透明度为1。重复播放和播放期间连点应保持正常。

## 生成

读取[输入示例](examples/config.json)，填入本篇文字与颜色。

```text
python <本Skill目录>/scripts/render.py --config <本次目录>/config.json --out <本次目录>/component.html --preview-out <本次目录>/preview.html
```

已有输出需替换时加 `--overwrite`。输入配置、片段、预览使用不同路径。脚本会保留文字与特殊符号，字段过长、缺项或路径冲突时给出具体说明。只使用Python3.10及以上标准库。

生成片段采用SVG与SMIL，实例事件ID分别生成。示例采用原创矢量与文字，按本篇材料替换后再交付。可先打开[交互预览](examples/preview.html)。

## 接入与检查

- 检查320、375px宽度中文字、按钮和画面边界。
- 同一篇放两份组件，分别操作，核对实例互不影响。
- 插入秀米前检查当前粘贴格式选项，保存重开后从阅读页检查实际动作。
- 事件放在带ID的组节点，初始显示状态同时写入属性与内联样式。接收端会清理部分属性时，按实际保留结构复查。
- 公众号同步、真实手机微信触摸与音频按相应功能实际检查。

[查看可操作演示](examples/brand-preview.html) · [查看GIF](examples/demo.gif) · [读取品牌样式与素材](examples/brand-style.json)

1. 先看GIF选择效果，再读取 `examples/brand-style.json` 和 `examples/brand-component.html`，确认本组件的画布、配色及素材。
2. 按本次任务采用使用者自己的头像、账号资料、正文与配图。直接修改本地品牌HTML模板和相邻素材即可复用单项包。原有生成器的参数能力以本Skill正文为准。
3. 文字保留原生编辑。图片放在对应动画组或状态组里，保留事件ID、SMIL时序与透明点击区。同篇放多个实例时，分别生成独立ID并同步事件引用。
4. 修改后检查完整动作与返回，核对文字、图片和按钮边界，再检查目标编辑器中的保存结果。

本版已有600px浏览器操作／播放采集、320／375px布局检查，GIF记录与实际文件校验一致。
