# 文字弹幕与循环轨道

让多条短句在三条轨道循环移动，支持开始重播与停止定格，完整文字始终保留在下方。

## 准备与生成

填写[配置示例](examples/config.json)。`messages`需要3至9项，每项`text`最多9字，可选`lane`为0、1、2，每条轨道最多3项。`duration`为单条穿过画面的秒数，支持8至24秒。停止后再次播放从头开始。

```text
python <本Skill目录>/scripts/render.py --config <配置路径> --out <输出目录>/component.html --preview-out <输出目录>/preview.html
```

需要覆盖既有输出时加 `--overwrite`。生成器采用 Python 标准库，拒绝非法数值、过长文案与无效XML字符，输出会保护输入配置和Skill源文件。每次生成使用独立事件ID。

打开[交互预览](examples/preview.html)查看，生成片段见[组件HTML](examples/component.html)。颜色采用六位HEX，`accent` 与 `background` 可按本人风格调整。品牌示例由组件库统一加入本人头像、纸纹及对应素材，头像与正文由本次使用者替换。

## 操作与核对

- 点击“开始／重播”观察各轨道，短句有足够阅读时间。
- 点击“停止定格”，检查画面停住，下方完整文字仍可阅读。
- 再次播放从起点开始，停止方式与继续播放的含义需向使用者说明。
- 同页双实例、320／375px和手机触摸需分别检查。

数据与文字保留原生SVG文本，配置示例中的数值和文案用于演示。按客户或文章材料填写实际内容。源片段采用SVG与SMIL，品牌插画槽可由本地模板添加素材。每个实例需保持ID及事件引用独立。

## 编辑器接入

已调研秀米“SVG → 文字弹幕”，模板设置路径为“布局模式 → 选中SVG布局 → 工具条动画 → 文字内容”，多层字幕分别设置。本Skill采用独立实现的三轨道短句，开始与停止由SVG事件控制。参考了弹幕教程的操作机制。[小红书弹幕参考](https://www.xiaohongshu.com/explore/6645a6ab000000001e037acb)

在秀米按当前可用入口导入或搭建对应原生效果，使用本人的素材完成保存重开，再检查公众号同步与手机微信显示。此版本提供本地可运行的浏览器组件；秀米保存、公众号同步与手机触摸的结果应按目标稿逐项核对。来源与调研记录由整库的研究清单关联，具体页面支持范围以本次实际操作为准。

## 品牌演示与GIF

[查看可操作演示](examples/brand-preview.html) · [查看GIF](examples/demo.gif) · [读取品牌样式与素材](examples/brand-style.json)

1. 先看GIF选择效果，再读取 `examples/brand-style.json` 和 `examples/brand-component.html`，确认本组件的画布、配色及素材。
2. 按本次任务采用使用者自己的头像、账号资料、正文与配图。直接修改本地品牌HTML模板和相邻素材即可复用单项包。原有生成器的参数能力以本Skill正文为准。
3. 文字保留原生编辑。图片放在对应动画组或状态组里，保留事件ID、SMIL时序与透明点击区。同篇放多个实例时，分别生成独立ID并同步事件引用。
4. 修改后检查完整动作与返回，核对文字、图片和按钮边界，再检查目标编辑器中的保存结果。

本版已有600px浏览器操作／播放采集、320／375px布局检查，GIF记录与实际文件校验一致。

品牌输出的秀米保存重开、公众号同步与真实手机微信效果待按目标环境核对。
