# 数据柱形图入场

调研时查看动态数据可视化案例的柱形、条形与其他图表展示。本包依据用户提供的数值生成柱形动画，完整数值持续可读，示例明确标为演示数据。[小红书参考案例](https://www.xiaohongshu.com/explore/6a759749000000002800ac34)

## 收集材料

提供标题、单位和2～5项 `items`，每项包含 `label` 与非负有限数字 `value`。分类名最多两行，每行约三个汉字。`max_value` 可选，须至少等于最大值。`duration` 为0.1～5秒。示例明确标为演示数据，正式内容采用本次已有数据。

强调色用 `accent`，底色用 `background`，均采用六位HEX颜色，沿用本篇主题。

## 生成

修改 [示例输入](examples/config.json)，再执行。

```text
python <本Skill目录>/scripts/render.py --config <本次目录>/config.json --out <本次目录>/component.html --preview-out <本次目录>/preview.html
```

已有输出需替换时加 `--overwrite`。脚本保护配置和原始图片，先暂存全部输出，再提交。发生写入错误时恢复已有文件，恢复遇到问题会报告备份路径。

生成文件采用内联SVG与SMIL。片段可组合到本次正文中。可打开 [交互示例](examples/preview.html) 查看效果。

## 检查

逐项核对标签、数值和柱高关系。点击播放，柱形从同一基线长出，静态数值始终可见。播放结束再点一次检查重播。零值保留标签，负数会报告输入问题。

在秀米导入时检查当前粘贴选项。保存重开后核对文字、关键组ID、动画及实际交互。

2026-11-12，Ego lite在375px与320px下的真实鼠标检查通过。本地预览和秀米独立测试稿保存重开后的阅读页，均通过两次播放与重播，三根示例柱的最终高度为 `60／125／200`，页面无横向溢出。公众号同步及真实手机微信触摸待测。

## 实现

按数值比例计算柱高，同时动画化矩形的高度与y坐标，使底部保持在基线上。数值文本独立于动画柱形。长数值在图上采用紧凑表示，发生取近似时标注≈，下方逐项保留输入数值。

每次生成采用独立的字母、数字、下划线事件ID，关键事件锚点放在组节点。新导入路径按实际保存结果复核。SVG机制参照 [W3C动画规范](https://www.w3.org/TR/SVG11/animate.html)。
