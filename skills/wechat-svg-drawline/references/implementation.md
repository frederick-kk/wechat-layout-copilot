# 实现与参数

画布内是一条水平路径。`pathLength="100"` 将长度归一化，虚线长度和偏移也按100设置。动画将偏移从100逐渐变成0，随后保持完整线条。根SVG保留完整线条的基础属性，因此静态查看时有可见分隔。

| 参数 | 默认值 | 含义 |
|---|---|---|
| `--color` | `#D97706` | 六位十六进制线色 |
| `--width` | 600 | SVG画布宽度 |
| `--height` | 48 | SVG画布高度 |
| `--stroke-width` | 3 | 路径线宽 |
| `--duration` | 2.8 | 一轮播放总秒数，前60%完成描边 |
| `--repeat` | 1 | 正整数播放次数，或 `loop` 持续循环 |

W3C描述了动画值、时长、重复和结束状态的含义。公众号里的实际保留情况通过本次编辑器保存及手机预览核对。[W3C SVG动画规范](https://www.w3.org/TR/SVG11/animate.html)

本次还阅读了MIT项目中的描边配方，了解了路径归一化的使用。当前组件独立实现单条分隔线。[调研配方](https://github.com/JamieJustTang/wechat-animating/blob/main/wechat-animating-authoring/references/smil-cookbook.md)

输入值会检查范围并转义进入HTML的文字。SVG内包含可访问描述。画布过矮或线宽超过画布会在生成时提示调整。

## 排错

- 只有完整线条而没有动画，检查保存后的 `animate` 标签及其属性是否保留。
- 宽度或线宽不合适，先调整画布和线宽，再看实际手机缩放效果。
- 循环过于显眼，将 `--repeat` 设为 `1`，或减少文章中的出现次数。

本组件的SVG使用内联路径与SMIL属性，字体和外部资源需求为零。
