# 双面翻牌

正面横向收窄到边缘，背面展开。再次操作可以翻回。适合一组有明确关系的短内容，例如问题与答案、原先想法与后来理解。

## 材料与生成

提供组件标题、正反两面的标题与正文。每面标题最多一行约13个全角字，正文最多四行。主题色使用六位HEX色值，动画总时长 `duration` 支持0.4～3秒。

可直接调整[配置示例](examples/config.json)中的 `title`、`front_title`、`front_body`、`back_title`、`back_body`。`accent`、`background` 为可选配色。

```text
python <本Skill目录>/scripts/render.py --config <本次目录>/config.json --out <本次目录>/component.html --preview-out <本次目录>/preview.html
```

已有输出需要替换时加 `--overwrite`。片段和预览使用 `.html` 或 `.htm`，输入配置、Skill说明和生成器受保护。脚本保留输入文字并做XML转义，缺项、超长或非法数值会报告字段。

打开[交互预览](examples/preview.html)，点击亮起的按钮。翻转过程中按钮暂停响应，结束后亮起反方向按钮，避免连点造成状态跳跃。

## 接入与检查

- 先翻到背面，再翻回正面，连续两轮核对标题和正文。
- 初始点灰色反向按钮、动画中连点、完成后重复点同向按钮，画面应保持合理状态。
- 在320、375px视口检查正文、按钮与边界，同篇两个实例分别操作。
- 导入秀米时核对粘贴格式选项，保存重开后从阅读页重新操作。
- 公众号同步、真实手机微信触摸与字体表现分别检查。

片段采用SVG与SMIL。事件ID每次独立生成，点击锚点位于 `g` 节点。初始可见性和按钮状态同时写入属性及内联样式。秀米清理自定义数据属性后，可用 `g[id^="flipcard_"][id$="_forward"]` 和 `_reverse` 定位动作。`_front`、`_back` 组的横向缩放分别在1与0之间切换。


调研时阅读了笔记正文的“点击展开＋点击翻牌”说明，采用双面翻牌方向，画面与代码独立编写。[小红书参考案例](https://www.xiaohongshu.com/explore/68652b03000000000d018842)

Ego lite独立预览和30项合并总页均在320、375px视口完成真实鼠标检查，无页面横向溢出。总页已复核主要动作和终态。独立前向生成、特殊字符、事件引用、双实例ID及源文件保护检查通过。秀米保存重开、公众号同步与真实手机微信触摸待验证。

## 品牌演示与GIF

[查看可操作演示](examples/brand-preview.html) · [查看GIF](examples/demo.gif) · [读取品牌样式与素材](examples/brand-style.json)

1. 先看GIF选择效果，再读取 `examples/brand-style.json` 和 `examples/brand-component.html`，确认本组件的画布、配色及素材。
2. 按本次任务采用使用者自己的头像、账号资料、正文与配图。直接修改本地品牌HTML模板和相邻素材即可复用单项包。原有生成器的参数能力以本Skill正文为准。
3. 文字保留原生编辑。图片放在对应动画组或状态组里，保留事件ID、SMIL时序与透明点击区。同篇放多个实例时，分别生成独立ID并同步事件引用。
4. 修改后检查完整动作与返回，核对文字、图片和按钮边界，再检查目标编辑器中的保存结果。

本版已有600px浏览器操作／播放采集、320／375px布局检查，GIF记录与实际文件校验一致。

品牌输出的秀米保存重开、公众号同步与真实手机微信效果待按目标环境核对。
