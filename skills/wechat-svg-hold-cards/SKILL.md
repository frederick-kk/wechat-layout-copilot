# 长按轮播与松手定格

调研参考了长按抽签演示与官方图集长按的松开停止行为。本包按松手时刻停在某张卡片，可用于轻互动或灵感选择。[小红书参考案例](https://www.xiaohongshu.com/explore/67d909c6000000000b014d2a)

按住卡片，内容连续轮播。松开停在当时的卡片，再次按住可重新轮播。这是按操作时刻定格的互动，卡片内容由使用者提供。

## 输入与生成

需要整体 `title`，以及3～6张按顺序排列的 `cards`。每张包括 `title` 和 `body`。缺少卡片时集中列出所需张数与内容，不替用户编造真实推荐或结果。

复制 [config.json](examples/config.json)，填写本篇的短内容。

```text
python <本Skill目录>/scripts/render.py --config <本次目录>/config.json --out <本次目录>/component.html --preview-out <本次目录>/preview.html
```

| 字段 | 要求 |
|---|---|
| `title` | 必需，一行总标题，约14个全角字以内 |
| `cards` | 必需，3～6个对象，各含一行`title`与最多四行`body` |
| `step_seconds` | 可选，每张停留0.1～2秒，默认0.24秒 |
| `accent`、`background` | 可选，六位HEX强调色与底色 |

片段采用SVG和SMIL。每次生成独立的组事件ID。文字超长、非法字符或参数缺项会得到具体说明。已有输出需要替换时使用 `--overwrite`。输入配置、片段、预览分别保存。

可打开 [交互预览](examples/preview.html)，按住卡片，再松手查看结果。

## 检查与接入

- 按住时观察至少一整轮，确认每一时刻只有一张卡片显示。
- 在不同时间松开，确认停留内容保持。松开后再等一轮时长，结果应保持。
- 再次按住后，检查轮播能够重新开始。按住后移出区域也应定格。
- 同篇双实例分别操作，确认彼此独立。
- 检查320/375px文字、按钮和触发范围。
- 秀米保存重开，再检查轮播与定格。手机微信实际触摸另行测试。

该组件按固定顺序轮播，停留页取决于松手时刻。公开内容中可称“轮播定格”或“抽签玩法”。需要概率控制或带奖品的抽奖时，先明确新的功能与规则。

2026-11-12已完成输入与结构检查。在Ego lite的320、375px视口中，本地预览与秀米保存重开后的阅读页均通过鼠标按住轮播、松开定格，松开后继续观察700ms仍停留在同一张，无页面横向溢出。公众号同步、真实手机微信触摸待验证。
