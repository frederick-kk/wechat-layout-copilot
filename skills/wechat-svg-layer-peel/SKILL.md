# 点击逐层掉落

读者每点击一次，当前卡片向下移出，露出下一张。最后一张保持静止，再点也能看到完整内容。刷新预览可重新体验。

## 输入与生成

准备按阅读顺序排列的两到八张卡片 JSON，每张包含 `title` 与 `body`。画布 600 × 420，标题一行，正文最多四行，每行约 14 个汉字。长文字先按原意拆卡，脚本会检查溢出。

输入例见 [cards.json](examples/cards.json)。在组件目录运行，按实际环境替换路径。

```powershell
python scripts/render.py --cards examples/cards.json --out output/peel.html --preview-out output/preview.html
```

可选 `--color "#D97706"`、`--background "#FFF8EE"`、`--duration 0.45`。已有输出需要替换时使用 `--overwrite`。

片段使用内联 SVG 和 SMIL 动画，无 JavaScript。所有卡片在同一画布中，从后往前堆叠，底层最终卡片没有移出动画。每次生成独立事件 ID，可合并多个实例。

## 检查

- 核对输入顺序与首次显示、逐层显示的内容一致。
- 点击到最后一张后，额外点击两次，检查底层仍在。
- 快速连点和正常节奏分别试一次，检查文字、画面与阅读滚动。
- 在 320 和 375 像素宽度确认无裁切与横向溢出。
- 在秀米保存重开，再通过本次排版路线检查公众号与手机交互。

4. 修改后检查完整动作与返回，核对文字、图片和按钮边界，再检查目标编辑器中的保存结果。
