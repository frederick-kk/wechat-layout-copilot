# 点击轨迹运动

调研时查看了轨迹动画的编辑画面。本包依据坐标参数生成原创贝塞尔路径，移动图形沿路径运动，线条和静态标签保留阅读参照。[小红书参考案例](https://www.xiaohongshu.com/explore/6933fef5000000001b020077)

## 收集材料

提供标题、可选短说明及四个路线点。`points` 依次为起点、两个控制点、终点，坐标基于600×430画布。x范围28～572，y范围126～308。`duration` 为0.3～10秒。默认路线可直接试用。

强调色用 `accent`，底色用 `background`，均采用六位HEX颜色，沿用本篇主题。

## 生成

修改 [示例输入](examples/config.json)，再执行。

```text
python <本Skill目录>/scripts/render.py --config <本次目录>/config.json --out <本次目录>/component.html --preview-out <本次目录>/preview.html
```

已有输出需替换时加 `--overwrite`。脚本保护配置和原始图片，先暂存全部输出，再提交。发生写入错误时恢复已有文件，恢复遇到问题会报告备份路径。

生成文件采用内联SVG与SMIL。片段可组合到本次正文中。可打开 [交互示例](examples/preview.html) 查看效果。

## 检查

点击播放，观察图形沿虚线经过，结束后再点一次。不同实例应各自运动。检查起点、终点及中途边缘裁切。

在秀米导入时检查当前粘贴选项。保存重开后核对文字、关键组ID、动画及实际交互。

2026-11-12，Ego lite在375px与320px下的真实鼠标检查通过。本地预览和秀米独立测试稿保存重开后的阅读页，均通过两次播放与重播，图形终点为 `(550,170)`，页面无横向溢出。公众号同步及真实手机微信触摸待测。

## 实现

使用 `animateMotion` 的字面量 `path`，避免依赖路径节点ID。图形、路线与按钮均为原创矢量素材。

每次生成采用独立的字母、数字、下划线事件ID，关键事件锚点放在组节点。新导入路径按实际保存结果复核。SVG机制参照 [W3C动画规范](https://www.w3.org/TR/SVG11/animate.html)。

## 品牌演示与GIF

[查看可操作演示](examples/brand-preview.html) · [查看GIF](examples/demo.gif) · [读取品牌样式与素材](examples/brand-style.json)

1. 先看GIF选择效果，再读取 `examples/brand-style.json` 和 `examples/brand-component.html`，确认本组件的画布、配色及素材。
2. 按本次任务采用使用者自己的头像、账号资料、正文与配图。直接修改本地品牌HTML模板和相邻素材即可复用单项包。原有生成器的参数能力以本Skill正文为准。
3. 文字保留原生编辑。图片放在对应动画组或状态组里，保留事件ID、SMIL时序与透明点击区。同篇放多个实例时，分别生成独立ID并同步事件引用。
4. 修改后检查完整动作与返回，核对文字、图片和按钮边界，再检查目标编辑器中的保存结果。

本版已有600px浏览器操作／播放采集、320／375px布局检查，GIF记录与实际文件校验一致。

品牌输出的秀米保存重开、公众号同步与真实手机微信效果待按目标环境核对。
