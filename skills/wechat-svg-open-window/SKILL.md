# 双扇开窗

调研参考点击开窗案例的前景与内容分层，以及秀米官方的双侧打开做法。本包用原创矢量窗扇生成可反复开合的固定画面。[小红书参考案例](https://www.xiaohongshu.com/explore/63e4ddc8000000001d0108cb)

点“点开窗户”，左右窗扇同时移出，显示里面的标题和短内容。点“合上窗户”回到初始画面。画布高度保持固定。

## 输入与生成

需要窗后的 `title`、`body`。沿用文章配色，用户已有前景图片时可交由秀米原生打开动画制作。这个生成器输出原创矢量窗扇与文字卡片。

复制 [config.json](examples/config.json) 并替换本次文字。

```text
python <本Skill目录>/scripts/render.py --config <本次目录>/config.json --out <本次目录>/component.html --preview-out <本次目录>/preview.html
```

| 字段 | 要求 |
|---|---|
| `title` | 必需，窗后标题，最多一行，约14个全角字 |
| `body` | 必需，短内容，最多四行，可用换行分段 |
| `cover_title` | 可选，窗扇上的短标题，默认“点开这扇窗” |
| `accent`、`background` | 可选，六位HEX强调色和底色 |
| `duration` | 可选，单次开合0.1～3秒，默认0.6秒 |

所有输入文字保留并做XML转义。超长或缺项时报告具体字段，等待合适的输入。已有输出需要替换时使用 `--overwrite`。片段、预览与输入配置采用不同路径。

可先打开 [交互预览](examples/preview.html) 看开合动作。

## 检查与接入

- 连续开合两轮，确认窗扇归位、里面文字完整。
- 在320/375px下检查标题、窗扇边界与按钮。
- 同篇多个实例由脚本生成独立事件ID，分别点按检查。
- 用本次排版工具导入秀米，保存重开后，再从阅读预览检查开合。
- 事件ID放在组节点，初始按钮状态写入内联样式。接收端会清理属性时，按实际保留的组和动画节点检查。

2026-11-12已完成输入与结构检查。在Ego lite的320、375px视口中，本地预览与秀米保存重开后的阅读页均通过两轮打开、合上操作，无页面横向溢出。公众号同步与真实手机微信点击待验证。

需要图片窗扇、上下打开或其他原生打开效果时，可参考秀米的SVG布局打开动画说明，按当前编辑器入口操作。[秀米官方SVG布局](https://b.xiumi.us/board/v5/2a5va/67957276)
