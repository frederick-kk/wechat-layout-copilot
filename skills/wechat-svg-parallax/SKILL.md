# 三层视差场景

用按钮触发远、中、近三层平移，目标位移分别为−40、−100、−180逻辑单位；返回动作恢复0。使用固定画布。

## 准备材料

提供标题、远景/中景/近景三段短标签，每段最多6个全角字。可配置主题色与0.2到3秒动画时长。缺少必需字段时集中说明缺项，取得实际文字后再制作。

## 生成与复用

修改[配置示例](examples/config.json)，运行本目录的生成器。

```text
python <本Skill目录>/scripts/render.py --config <本次目录>/config.json --out <本次目录>/component.html --preview-out <本次目录>/preview.html
```

已有输出需要替换时使用`--overwrite`。配置、片段和预览采用不同路径。生成器保留输入文字、转义XML特殊字符、检查字数和有限数值，覆盖输出时使用磁盘备份与事务恢复。输入配置、Skill和脚本受到路径保护。

可配置`accent`、`background`六位HEX色值及`duration`动画秒数。片段采用SVG和SMIL，每次生成独立事件ID。整包或独立目录均可由能读文件的AI使用。

## 纸纹插画版本

使用[插画配置](examples/artwork-config.json)生成[插画交互预览](examples/artwork-preview.html)。标题、三段标签和按钮文字保留为可修改的原生文字。

```text
python <本Skill目录>/scripts/render.py --config <本Skill目录>/examples/artwork-config.json --out <本次目录>/artwork-component.html --preview-out <本次目录>/artwork-preview.html
```

`artwork`包含`far`远景、`middle`中景、`near`近景三张图片，另可提供`paper`纸纹。路径相对JSON配置文件，支持本地PNG、JPEG和WebP。建议按实际展示尺寸准备素材。图片嵌入生成的HTML，独立预览可离线打开。图片文件与配置一样受到输出路径保护。

- 三张场景图使用相同的2.5∶1画布，绘制到840×336逻辑区域，在600×336窗口中显示。右侧保留240逻辑单位供场景移动。
- 创作素材时先统一人物和画风，再分别生成远处山景、中层校园建筑、近处橙帽人物与桌面。暖白折痕纸纹、轻水彩和少量暖橙贯穿三层，图片里不绘制标题、按钮或标签。
- 当前近景作者图向右预留140逻辑单位的初始偏移，保证移动−180之后人物仍在窗口内。更换人物构图时检查起点与终点，并据实际位置调整该偏移。
- 远景铺满画布，中景和近景保留真实透明区域，避免挡住后面的景物。前进终态分别移动−40、−100、−180，回到起点时全部归零。
- 画面窗口独立裁切，移动层只包含图片，底部标签和按钮保持静止。
- 替换素材时同时检查起点和终点，确认右边未露空、人物没有被窗口意外截断，图中文字没有与原生标签重复。
- 嵌入图片目前供便携预览使用。导入秀米时需要检查图片是否保留，必要时上传为编辑器支持的素材链接，再保存重开验证。

原有[配置示例](examples/config.json)和[矢量交互预览](examples/preview.html)继续使用原来的绘制方式。插画版的秀米保存重开、公众号同步和手机微信效果需另行验收。

## 实际操作

点击向前看看，再点击返回起点，观察三个景层的速度差。

打开[交互预览](examples/preview.html)试用。本地按钮`[data-action="forward"]`和`[data-action="back"]`。秀米保存后用`g[id^="parallax_"][id$="_forward"或"_back"]`，景层后缀`_far`、`_middle`、`_near`。读取各组`transform.animVal`，前进终态横移−40/−100/−180，返回均为0。
