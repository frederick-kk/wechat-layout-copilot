# 长按显影与松手复原

调研时查看了长按玩法的秀米设置画面，并核对官方对松开后回退的说明。制作时将触发区域放在效果层上方，保证显影后仍能收到松开动作。[小红书参考案例](https://www.xiaohongshu.com/explore/6703c2ad000000001b021261)

按住卡片，答案逐渐出现。松开或移出卡片，恢复初始画面。触发区始终位于同一位置，答案层不会改变触发区。

## 输入与生成

需要初始 `title`、显示后的 `revealed_title` 和 `body`。使用文章本身的颜色与短内容。

复制 [config.json](examples/config.json) 并替换文字。

```text
python <本Skill目录>/scripts/render.py --config <本次目录>/config.json --out <本次目录>/component.html --preview-out <本次目录>/preview.html
```

| 字段 | 要求 |
|---|---|
| `title` | 必需，初始标题，最多一行 |
| `revealed_title` | 必需，显影内容标题，最多一行 |
| `body` | 必需，最多四行短内容 |
| `accent`、`background` | 可选，六位HEX强调色与底色 |
| `duration` | 可选，显影0.1～3秒，默认0.5秒 |

标题每行约14个全角字。正文过长时报告实际行数，先精简或拆分，再生成。输入中的特殊字符经XML转义，输出路径保护输入配置。已有输出可通过 `--overwrite` 明确替换。

打开 [交互预览](examples/preview.html)，用鼠标在卡片上按住、保持、松开。

## 检查与接入

1. 按下后保持超过显影时长，检查答案持续显示。
2. 松开恢复，随后再次按住，检查可重复。
3. 按住后移出卡片，检查恢复初态。
4. 在320/375px检查触发范围与文字边界。
5. 导入秀米后保存重开，检查初始隐藏样式、触发组ID和动作。
6. 在目标手机微信实际按住和松开，检查长按菜单是否干扰阅读。

触发组包含固定透明命中区域。答案层通过SMIL可见区间控制，内部透明度动画只负责渐显。片段同时列出鼠标和触摸事件，手机触摸支持以目标设备实际结果为准。

2026-11-12已完成输入与结构检查。在Ego lite的320、375px视口中，本地预览与秀米保存重开后的阅读页均通过鼠标按住显影、松开复原，无页面横向溢出。公众号同步、真实手机微信触摸与长按菜单表现待验证。

若目标入口清理持续按压事件，可用秀米原生“长按触发 → 松开后回退”配置同一交互。[秀米官方SVG布局](https://b.xiumi.us/board/v5/2a5va/67957276)

## 品牌演示与GIF

[查看可操作演示](examples/brand-preview.html) · [查看GIF](examples/demo.gif) · [读取品牌样式与素材](examples/brand-style.json)

1. 先看GIF选择效果，再读取 `examples/brand-style.json` 和 `examples/brand-component.html`，确认本组件的画布、配色及素材。
2. 按本次任务采用使用者自己的头像、账号资料、正文与配图。直接修改本地品牌HTML模板和相邻素材即可复用单项包。原有生成器的参数能力以本Skill正文为准。
3. 文字保留原生编辑。图片放在对应动画组或状态组里，保留事件ID、SMIL时序与透明点击区。同篇放多个实例时，分别生成独立ID并同步事件引用。
4. 修改后检查完整动作与返回，核对文字、图片和按钮边界，再检查目标编辑器中的保存结果。

本版已有600px浏览器操作／播放采集、320／375px布局检查，GIF记录与实际文件校验一致。

品牌输出的秀米保存重开、公众号同步与真实手机微信效果待按目标环境核对。
