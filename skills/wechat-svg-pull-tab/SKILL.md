# 侧边抽拉标签

从侧边口袋横向抽出纸条，展开后显示文字，再收回。两次动作都通过可见标签点击触发，画布高度固定。

## 准备材料

提供标题、口袋短标签和信息条正文。标签最多3个全角字，正文每行约8字、最多4行。缺少必需字段时集中说明缺项，取得实际文字后再制作。

## 生成与复用

修改[配置示例](examples/config.json)，运行本目录的生成器。

```text
python <本Skill目录>/scripts/render.py --config <本次目录>/config.json --out <本次目录>/component.html --preview-out <本次目录>/preview.html
```

已有输出需要替换时使用`--overwrite`。配置、片段和预览采用不同路径。生成器保留输入文字、转义XML特殊字符、检查字数和有限数值，覆盖输出时使用磁盘备份与事务恢复。输入配置、Skill和脚本受到路径保护。

可配置`accent`、`background`六位HEX色值及`duration`动画秒数。片段采用SVG和SMIL，每次生成独立事件ID。整包或独立目录均可由能读文件的AI使用。

## 实际操作

点击“拉”标签抽出信息，阅读后点击“收”放回。

打开[交互预览](examples/preview.html)试用。本地`[data-action="open"]`与`[data-action="close"]`；秀米用`g[id^="pull_"][id$="_open"或"_close"]`。纸条组`_paper`的横移从−310到0，再返回−310；正文组`_message`只在展开后可见。

## 检查与接入

- 核对本次文字、配色和阅读顺序。
- 重复完整操作两轮，检查初始状态、动作中连点、结束后的返回或改选。
- 在320、375px阅读宽度检查文字和按钮边界。
- 同篇两个实例分别操作，确认事件ID隔离。
- 插入秀米前核对当前粘贴格式选项，保存重开后用阅读页重新操作。
- 公众号同步、手机微信触摸和长按菜单按本次目标环境实际检查。

4. 修改后检查完整动作与返回，核对文字、图片和按钮边界，再检查目标编辑器中的保存结果。
