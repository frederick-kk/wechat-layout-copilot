# 单题点击答题

调研参考点击不同选项出现相应反馈的动画组结构。题目、答案和解释由本次使用者提供，每项反馈都带重选入口。[小红书参考案例](https://www.xiaohongshu.com/explore/6856ad3e000000002201c134)

读者点一个选项，看到该答案对应的解释，点返回可以重选。正确答案与解释由本次材料确定。

## 准备材料

需要题目、2到4个选项，以及每个选项的反馈文字。单选题恰好一个选项标记 `correct:true`。先核对题目的事实依据，确认各选项确实可以判断，再制作互动。

题目最多两行，选项最多一行，反馈最多五行。长解析放在组件下方的普通正文。

## 生成

替换[输入示例](examples/config.json)中的 `question` 和 `choices`。`accent` 与 `background` 可配文章主题。

```text
python <本Skill目录>/scripts/render.py --config <本次目录>/config.json --out <本次目录>/component.html --preview-out <本次目录>/preview.html
```

每个选项包含 `label`、`correct`、`feedback`。已有输出需要替换时，加 `--overwrite`。片段使用SVG与SMIL，导出内容没有JavaScript，事件ID每次独立生成。

## 检查

- 逐个选择所有选项，核对反馈与正误判断。
- 每个反馈点返回，再次选择同一项，检查能重复作答。
- 两个实例放在同一篇，检查各自反馈互不影响。
- 320、375像素阅读宽度检查题目换行、按钮与反馈边界。
- 插入秀米后保存重开，重新选择各答案。公众号同步、手机微信点击另行检查。

初始反馈层同时用属性与内联样式隐藏，点击和返回锚点放在组节点。已完成脚本、输入与结构检查。2026-11-12使用Ego lite实际鼠标，在320、375像素宽度下，本地预览与秀米保存重开后的阅读页均通过三个答案的反馈、重复作答和重选检查，页面无横向溢出。公众号同步及真实手机微信触摸待验证。可打开[组件预览](examples/preview.html)试题目。
