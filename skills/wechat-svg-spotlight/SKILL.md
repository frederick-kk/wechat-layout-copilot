# 探照灯窗口

按钮选择左、中、右三个固定位置，圆形窗口显示底层相应内容。全景显示全部内容，复原回到中间窗口。各状态在固定画布内切换。

## 准备材料

提供标题和三组短标签、正文，每组标签最多3个全角字，正文每行约4字、最多2行。缺少必需字段时集中说明缺项，取得实际文字后再制作。

有配图时提供一张无字横向场景图，建议把三个想让读者观察的对象放在左、中、右三个区域。配图版以整张插画为底图，圆孔只显示画面细节，标题、标签、正文和按钮保持独立文字。没有配图配置时，沿用原有的矢量文字版，标签和正文完整呈现在光圈内。

## 生成与复用

修改[配置示例](examples/config.json)，运行本目录的生成器。

```text
python <本Skill目录>/scripts/render.py --config <本次目录>/config.json --out <本次目录>/component.html --preview-out <本次目录>/preview.html
```

已有输出需要替换时使用`--overwrite`。配置、片段和预览采用不同路径。生成器保留输入文字、转义XML特殊字符、检查字数和有限数值，覆盖输出时使用磁盘备份与事务恢复。输入配置、Skill和脚本受到路径保护。

可配置`accent`、`background`六位HEX色值。光圈按按钮选定的位置直接切换。片段采用SVG和SMIL，每次生成独立事件ID。整包或独立目录均可由能读文件的AI使用。

### 配图版

打开[配图交互预览](examples/artwork-preview.html)查看新增样例，修改[配图配置](examples/artwork-config.json)后用同一个生成器重新生成。原有示例保留。

在配置中增加`artwork`。`scene`是必填场景图，`paper`是可选纸纹。路径相对于配置文件所在目录，独立Skill的素材放在`assets/`内。

```json
"artwork": {
  "scene": "../assets/studio-exploration-v1.png",
  "paper": "../assets/paper-white-folds.png"
}
```

图片接受本地PNG、JPEG或WebP。建议按实际显示尺寸准备素材，通常600至1200px宽足够预览使用。生成器将图片嵌入片段，移动HTML后仍能离线显示。配图版默认使用暖橙与米白，可通过颜色字段修改。画布为600×800，场景窗口为600×360，三个光圈中心横坐标分别为112、300、488，纵坐标在场景中为180。文字保持在场景下方。

公众号和秀米可能过滤内嵌图片或SVG属性。导入时先测试小片段，按编辑器要求上传真实图片并替换为受支持的素材地址，核对动画中的所有图片引用。导入后保存、重开阅读页再操作。本地显示成功不能证明同步后的公众号与手机触摸效果。

## 实际操作

点击左、中、右按钮切换圆形窗口，也可查看全景或复原。

打开[交互预览](examples/preview.html)试用。本地用`[data-action="left|center|right|full|reset"]`定位。秀米保存后用`g[id^="spot_"][id$="_left"等]`定位，三层`g[id$="_cover_0/1/2"]`分别对应左、中、右罩层。全景时三层均隐藏，复原时仅中间层可见。

## 检查与接入

- 核对本次文字、配色和阅读顺序。
- 重复完整操作两轮，检查初始状态、动作中连点、结束后的返回或改选。
- 在320、375px阅读宽度检查文字和按钮边界。
- 同篇两个实例分别操作，确认事件ID隔离。
- 插入秀米前核对当前粘贴格式选项，保存重开后用阅读页重新操作。
- 公众号同步、手机微信触摸和长按菜单按本次目标环境实际检查。
