# 点击旋转切换

将两到八张短卡片放入同一个固定高度画面。点击底部按钮切换，最后一张返回第一张。转场采用轻微旋转加淡入。

## 输入与生成

准备按顺序排列的卡片 JSON，每张包含 `title` 与 `body`。已有正文时保留原意，长内容可拆卡。固定画布为 600 × 420，标题最多约 14 个汉字，正文最多四行，每行约 14 个汉字。脚本会拒绝溢出的内容。

输入例见 [cards.json](examples/cards.json)。在组件目录运行，路径按实际环境替换。

```powershell
python scripts/render.py --cards examples/cards.json --out output/switch.html --preview-out output/preview.html
```

可选 `--color "#158A9A"`、`--background "#FFFDF7"`、`--duration 0.36`。已有输出需要替换时使用 `--overwrite`。

输出片段含内联 SVG 和 SMIL 动画，无 JavaScript。每次生成使用独立事件 ID，可在一篇文章中放多个实例。将片段交给本次公众号排版流程，预览文件用于浏览器检查。

## 检查

- 在 320 和 375 像素阅读宽度检查换行、按钮与边缘裁切。
- 依次点击所有卡片，再从末张返回，连续两轮检查第一张与最后一张。
- 多实例合并后分别点击，确认另一个实例保持原状态。
- 在秀米保存重开，确认 SVG、事件 ID 与交互仍在。进入公众号后再检查实际手机表现。

2. 按本次任务采用使用者自己的头像、账号资料、正文与配图。直接修改本地品牌HTML模板和相邻素材即可复用单项包。原有生成器的参数能力以本Skill正文为准。
3. 文字保留原生编辑。图片放在对应动画组或状态组里，保留事件ID、SMIL时序与透明点击区。同篇放多个实例时，分别生成独立ID并同步事件引用。
4. 修改后检查完整动作与返回，核对文字、图片和按钮边界，再检查目标编辑器中的保存结果。
