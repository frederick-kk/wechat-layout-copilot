# 点击擦拭前后对比

调研参考图层擦出上色的视觉思路。本包用按钮控制正向和反向擦拭，所需两幅画面在同一画布上对齐。[小红书参考案例](https://www.xiaohongshu.com/explore/69422fb1000000001d03d461)

两幅画面保持同尺寸，点击“查看制作后”横向擦出第二幅，点击“回到制作前”恢复。组件使用按钮控制擦拭，可反复比较。

## 准备材料

取得两组内容或两幅图片，分别标明制作前、制作后。文字模式每组提供 `label`、`title`、`body`，生成原创信息卡。图片模式每组提供 `label` 与 `image`。底色、强调色与文章保持一致。

本地图片支持PNG、JPEG、WebP，嵌入结果便于离线预览。也可提供HTTPS图片地址，实际加载在接收端检查。图片采用完整留边方式，先用同一尺寸画布对齐主体。

## 生成

替换[输入示例](examples/config.json)中的材料后运行。

```text
python <本Skill目录>/scripts/render.py --config <本次目录>/config.json --out <本次目录>/component.html --preview-out <本次目录>/preview.html
```

`title`最多一行，每组标签最多约六个汉字，标题最多两行、正文最多四行。`duration`可设0.15到3秒。`image`相对路径按JSON所在目录解析。已有输出需要替换时，加 `--overwrite`。

输出片段用固定宽度的嵌套SVG视口裁切。窗口横向移动，内部内容做等量反向移动，使原图保持原位并逐步露出。窗口固定高度和宽度同时写入内联样式，适配编辑器对SVG尺寸的处理。

初始仅“查看制作后”可点击，切换期间两个按钮暂时变淡，结束后亮起反方向按钮。变淡的按钮暂停响应，避免重复点击重启动画。事件ID每次独立生成，关键触发ID位于组节点，按钮状态也由SVG与SMIL控制。

## 检查

- 初始显示制作前，正向擦拭后完整显示制作后。
- 反向按钮恢复制作前，再重复一次。
- 图片主体、比例与两张图注对应，文字边缘完整。
- 同篇放两个实例，分别点击检查互不影响。
- 在320、375像素宽度检查按钮、文字和页面溢出。
- 插入秀米后保存重开，重新点击正反方向，再检查公众号手机预览。

本轮已完成脚本、输入与结构检查。在Ego lite的320、375px视口中，本地预览与秀米保存重开后的阅读页均通过两轮正反擦拭、初始禁用按钮、重复同向点击和动画中反向连点，无页面横向溢出。已检查前后实际画面。公众号同步与真实手机微信触摸待验证。可打开[组件预览](examples/preview.html)试效果。
