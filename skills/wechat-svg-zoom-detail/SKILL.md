# 同图局部放大与返回

## 收集材料

提供标题和要看的区域。`focus` 为 `[x,y,width,height]`，坐标基于600×360的原始画面，矩形须在画布内。可提供 `image` 为本地PNG/JPEG/GIF/WebP或完整HTTPS图片地址。相对路径基于配置目录。本地图片嵌入原型，进入编辑器时按实际要求转存图片地址。缺图时采用本包原创矢量演示。

强调色用 `accent`，底色用 `background`，均采用六位HEX颜色，沿用本篇主题。

## 生成

修改 [示例输入](examples/config.json)，再执行。

```text
python <本Skill目录>/scripts/render.py --config <本次目录>/config.json --out <本次目录>/component.html --preview-out <本次目录>/preview.html
```

已有输出需替换时加 `--overwrite`。脚本保护配置和原始图片，先暂存全部输出，再提交。发生写入错误时恢复已有文件，恢复遇到问题会报告备份路径。

生成文件采用内联SVG与SMIL。片段可组合到本次正文中。可打开 [交互示例](examples/preview.html) 查看效果。

## 检查

点放大细节，确认同一幅图的视野确实缩小并放大。点返回全景，再重复一次。自有图片先核对留边后的坐标，再检查放大位置与加载。

在秀米导入时检查当前粘贴选项。保存重开后核对文字、关键组ID、动画及实际交互。

2026-11-12，Ego lite在375px与320px下的真实鼠标检查通过。本地预览和秀米独立测试稿保存重开后的阅读页，均通过两次局部放大与返回，视野在 `(290,70,260,156)` 和 `(0,0,600,360)` 之间切换，页面无横向溢出。公众号同步及真实手机微信触摸待测。

## 实现

动画改变嵌套SVG的 `viewBox`，在固定画布中形成镜头缩放。原始图片按完整留边放入600×360画布。调研参考点击放大案例，仅采用同图放大的交互方向。[参考案例](https://www.xiaohongshu.com/explore/68ab2c2c000000001d00d6b1)

每次生成采用独立的字母、数字、下划线事件ID，关键事件锚点放在组节点。新导入路径按实际保存结果复核。SVG机制参照 [W3C动画规范](https://www.w3.org/TR/SVG11/animate.html)。
