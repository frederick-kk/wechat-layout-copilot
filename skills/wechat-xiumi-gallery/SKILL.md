# 秀米图片图集

## 先收齐材料

需要用户的图片文件或可访问地址、图片顺序、放置位置，以及希望手动滑动还是点击或自动播放。用户有图注和主题要求时一并采用。图片比例不同时先给出裁切或留边方案，让用户看见完整主体。

缺图时列出所需张数与用途，例如“还需要三张按制作顺序排列的流程截图”。没有指定自动播放时，先采用手动滑动，让用户保留阅读节奏的控制。

## 先生成可组合的图集片段

本组件增加 Python 3.10+ 标准库脚本，可制作两种浏览器原型。

| 模式 | 表现 | 适用位置 |
|---|---|---|
| `scroll` | 左右滑动，卡片显示完整图片与可复制图注 | 多张作品、流程截图、参考图合集 |
| `click` | 每次点击切到下一张，最后一张持续显示 | 固定位置逐张演示、分步效果与前后对比 |

图片按 JSON 中的顺序展示。一个图片条目静态显示。多个点击图集可同篇组合，事件采用各自局部结构。

### 输入与生成

将本次图片信息保存为 JSON。相对路径以 JSON 文件所在目录为基准，Windows 路径也可以使用正斜杠。

```json
{
  "mode": "scroll",
  "fit": "contain",
  "aspect_ratio": [16, 9],
  "images": [
    {"src": "images/01.png", "alt": "第一张制作前截图", "caption": "制作前，信息尚未分组"},
    {"src": "images/02.png", "alt": "第二张制作后截图", "caption": "制作后，标题与内容层级更清楚"}
  ]
}
```

```text
python <本Skill目录>/scripts/render.py --spec <本次目录>/gallery.json --out <本次目录>/gallery.html --preview <本次目录>/gallery-preview.html
```

同一份材料想看点击切换效果，可增加 `--mode click`。已有输出须在本次允许替换后加 `--overwrite`。输出先全部暂存再提交；写入失败时恢复已有文件并移除本次新文件，JSON 中列出仍保留的输出或待处理的恢复问题。

| 字段 | 要求 |
|---|---|
| `images` | 非空有序列表，每张包含 `src` 与简短 `alt`，`caption` 可选 |
| `src` | 本地 PNG、JPEG、GIF、WebP 文件，或完整 HTTPS 图片地址 |
| `hosted_src` | 本地图片上传后的 HTTPS 地址，可放在对应图片条目中 |
| `fit` | 默认 `contain`，保留完整图片并留边；`cover` 等比放大并裁切超出部分 |
| `aspect_ratio` | 默认 `[16,9]`，两个大于0的数字表示图片展示框宽高比 |
| `theme` | 可选 `accent`、`text`、`muted`、`surface`、`border` 六位 HEX 色值 |

本地图片会嵌入预览页，预览可以离线查看。提供 `hosted_src` 后，正式片段使用该地址，预览继续嵌入本地原图。直接提供 HTTPS `src` 时，预览依赖该地址，脚本只检查地址格式。结果中的 `hosted_image_urls_provided` 表示已提供地址，实际加载和编辑器效果继续核对。

缺少 `hosted_src` 的本地图片仍可生成嵌图原型，结果会列出 `missing_hosted_src_for_images`。用于编辑器时，先通过其上传入口取得图片地址，补入 JSON 重新生成，再核对导入结果。

### 图注与结束状态

`scroll` 的图注使用普通 HTML 文字，按卡片宽度换行。`click` 的图注和图片放在同一个 SVG 层中，一起切换。点击图集的图注采用36单位字号、44单位行距，每行约15个全角字，最多三行。超长时脚本报告具体图片与行数，保留原文等待精简版本，或改用横滑模式。

输入中的文字和图片地址须能表示为有效 XML。出现非法控制字符或孤立代理字符时，脚本报告图片序号、字段和 Unicode 编号，等待修正后再生成。

点击图集最底层图片保持静态，前面的图层逐次移出。最后一张没有移出动画和点击热区，可持续停留。刷新浏览器预览可重新开始。

生成片段的浏览器表现、秀米导入保存和微信手机行为分别验证。需要在秀米原生图集设置面板里继续编辑时，使用下方原生入口。

## 当前操作入口

2026-11-11 在已登录秀米图文编辑器中看到“图文模板 → 布局 → 基础布局”。该分类包含 SVG 图集、左右滑动布局、上下滑动布局及固定比例布局。

实际操作浏览器前，读取当前工具的用法。Ego lite 环境执行 `ego-browser skill` 获取当前指令。先识别本次独立草稿，沿用用户自己的素材和登录状态。

### 左右滑动图片

1. 插入“左右滑动布局”，点击布局边框进入“设置滑动序列”。
2. 删除示例内容，将本次图片依次加入序列。选中某一项时替换该项，未选中项时添加到末尾。
3. 根据实际图片设置列宽、对齐和间距，核对图注与对应图片。
4. 需要吸附效果时测试“滑动时自动对齐”。当前模板说明要求此类增强滑动经同步或插件上传公众号，手机中继续核对。

### SVG 图集

1. 从“基础布局”插入“SVG图集”，打开“图集设置”。
2. 删除灰色示例图，把用户图片按顺序添加。
3. 按目标选择滚动或轮播效果，设置“点击”或“自动”触发。填写本次切换时间，并用整篇预览检查节奏。
4. 复制图集序列或增加图片后，再核对首尾画面和最后一帧的行为。
5. 按秀米当前提示使用同步或插件方式进入公众号。官方教程与当前组件说明都提示 SVG 图集直接复制粘贴可能出现问题。

## 保存与检查

- 在秀米保存并重新打开，逐张核对图片、顺序、比例、图注及切换设置。
- 同步到公众号后，重新打开目标草稿，核对图片和 SVG 是否保留。
- 手机预览检查滑动、点击、停留时间、首尾状态和纵向阅读是否顺畅。
- 只有取得对应结果，才在交付里写已完成该项。需要用户扫码或登录时明确交接，等其确认后继续。
