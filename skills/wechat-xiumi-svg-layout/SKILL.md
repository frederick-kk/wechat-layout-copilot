# 秀米原生 SVG 布局

用户希望制作点击展开、开窗、掉落或局部点击效果时使用。先把效果说清楚，再按需要读取本页对应做法。

## 先判断需要哪些材料

| 效果 | 需要提供 |
|---|---|
| 点击展开后续内容 | 点击前画面、展开后的文字或图片、放置位置 |
| 开窗或开门 | 前景遮挡图、背后内容图、打开方向 |
| 多层点击掉落 | 按出现顺序排列的分层素材、每层动作 |
| 长按由模糊变清晰 | 同一画面的清晰版与模糊版，尺寸一致 |
| 局部热区显示细节 | 全图、细节图、热区位置，两图尺寸关系 |

先检查用户已给材料。缺项集中说明，例如“还需要同尺寸的窗户前景图和窗后图片，并告诉我左右开还是上下开”。已有风格要求时采用它的色彩和留白。

## 进入原生编辑器

读取当前可用浏览器工具说明。Ego lite 环境先执行 `ego-browser skill`，使用用户已有登录状态。定位本次目标草稿或按用户要求新建测试稿。

秀米入口为“图文模板 → 布局 → 基础布局 → SVG布局”。选中插入的布局，通过工具条的编辑或动画按钮进入设置。当前官方说明中，界面包含 SVG 动画层和内容层。显示内容、隐藏内容用于修改底层展开内容。

先放一组少量素材验证，再复制或增加层。动画层的宽高比按本次图像设置，检查所有层的对齐。素材支持范围以当前上传入口为准。

## 做法

### 点击展开

把点击前画面放在动画层，后续文字或图片放在内容层。触发方式选择点击，按目标配置淡出、移出、掉落或翻转等效果，再设置展开。返回图文编辑界面，使用“显示内容”检查底层，修改完成后恢复预览状态。动画层的堆叠与出场顺序都要用整篇预览确认。

### 开窗与开门

把前景图放在动画层，窗后或门后图片放在内容层。选择打开动画和左右或上下方向，再设置时长。官方说明打开动画采用图片，当前层的效果组合按编辑器可用项选择。此类打开效果按官方要求通过同步进入公众号。

### 多层点击掉落

将素材按照预期显示与移出的关系放入多层。分别设置点击触发、移出或掉落方向和时长。每加一层就预览一次，记录哪一层在最前。素材顺序在预览中以实际遮挡与点击结果为准。

### 长按渐显

清晰图放在内容层，模糊图或遮罩放在动画层。选长按触发和淡出，再根据用户目标选择松开后停止、回退或继续。预览时分别观察按下、保持、松开三个状态。

### 局部热区

在动画层调整触发区的大小与位置，确认是否需要非触发区穿透。把热区与实际图中对象对齐。底层图片按需要设置禁止点击放大，检查点击是否被图片自身放大行为截获。

需要多个可反复打开并返回的短说明时，可从[总预览的多热区组件](https://frederick-kk.github.io/wechat-layout-copilot/examples/preview.html#component-wechat-svg-hotspots)另行下载对应Skill。原生布局中每个目标都检查自己的触发区与返回区。总图和细节图统一画布，避免残留的底图挡住后面的热区。

### 中间层固定、上下层滑动

先取得背景、固定中间元素和前景三个独立素材。按目标方向设置滑动序列，再调整重叠次序。秀米官方演示说明，未设置重叠次序的背景或贴纸呈现背景关系，设置重叠次序后可形成上层前景关系。固定层需要让下方元素继续接收操作时，检查点击穿透。

逐层检查遮挡、滑动方向和纵向阅读。前景采用透明留空素材时，检查透明区域是否仍截获点击。该做法来自官方演示，本包尚未完成这类新稿的保存与手机验证。[秀米官方演示](https://www.xiaohongshu.com/explore/6ad0532a000000001801340f)

## 组合动画的关键设置

- 点击后继续自动播放的层，按一个动画组检查。官方说明同组动画采用一致的入场或出场方向关系，展开或收缩放在组末尾。
- 打开动画使用图片，选择左右或上下。官方说明同层设置打开后不能再叠加其他动画。
- 长按布局的松开行为有停止、回退、继续三种。原生 SVG 图集长按的松开行为按官方说明固定为停止。
- 点击＋自动、打开动画及原生 SVG 图集按官方要求通过同步进入公众号。粘贴后的动画保留情况另行检查。

这些参数依据当前读取的官方说明。制作时同时核对当前编辑器可见选项。[秀米官方 SVG 布局](https://b.xiumi.us/board/v5/2a5va/67957276)

## 保存与复核

1. 预览点击前、触发中、结束后的画面，确认层级和内容完整。
2. 缩放编辑预览宽度，检查热区与图片是否对应。
3. 保存并重新打开秀米草稿，检查素材、参数与顺序。
4. 按当前组件提示通过同步或插件进入公众号草稿，再保存重开。
5. 手机微信预览实际点击、长按和松开，检查返回、重复触发和阅读滚动。

遇到编辑器与手机表现不同，记录具体素材、触发、结束状态及导入方式，针对该组件调整。材料不足时保留可审阅部分，明确需要补充的文件和目标。
